# Draw.io Diagrams

The editable drawio files in this folder are source diagrams for the
Kinship Verification Framework.

- use-case-diagram.drawio
- sequence-kinship-verification.drawio
- sequence-marriage-eligibility.drawio
- kinship-algorithm-flowchart.drawio
- marriage-eligibility-flowchart.drawio
- class-diagram.drawio
- activity-diagram.drawio
- erd-diagram.drawio
- implementation-architecture.svg
- seeded-cross-family-generation.svg

The implementation architecture figure reflects the current Next.js, FastAPI,
SQLAlchemy, PostgreSQL, and Alembic code paths.

The cross-family generation figure follows the current seed migration. It shows
the existing Rivers and Imo people, their spouse edge, and the two new children
with their four stored parent edges.

Open any file in diagrams.net with File > Open From > Device.
